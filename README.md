# MIMIC-Skills: Improving Clinical Decision-Making with Evolutionarily Optimized Agent Skills

## Summary

This project improves LLM performance on the autonomous clinical decision-making
benchmark established by [Hager et al. (Nature Medicine, 2024)](https://www.nature.com/articles/s41591-024-02973-y)
by injecting **evolutionarily optimized clinical reasoning skills** — plain-text
prompt instructions generated by Claude Opus 4.6 from analysis of agent failure
trajectories and MIMIC-IV discharge summaries.

**Core result**: Evolved skills improve diagnostic accuracy by **+8 to +10 pp**
on abdominal pathologies and **+6 to +13 pp** on cardiac pathologies, while
transforming agent behavior to match clinical standards (PE-first compliance:
8% to 99%).

---

## Experimental Setup

| Dimension | Value |
|---|---|
| Student model | Qwen3.5-35B-A3B (open-weight, locally hosted via vLLM) |
| Evolver model | Claude Opus 4.6 (generates/refines skills from failure analysis) |
| Comparator model | Claude Sonnet 4.6 (frontier cloud model, baseline only) |
| Training set | 10 patients/pathology (4 abdominal or 3 cardiac) |
| Test set | 100 patients/pathology, 12 pathologies total (711 patients) |
| Evolution episodes | 10 per configuration, 8 configurations |
| Agent architecture | ZeroShotAgent (Hager et al. framework, LangChain) |
| Patient interaction | Patient simulator mode (agent receives chief complaint only) |
| Skill injection | Examples slot in CHAT_TEMPLATE (Approach 2) |
| Lab annotations | Enabled (annotate_clinical=True) |
| max_tokens ablation | 1024, 2048, 4096 (default), 8192 |

### Pathologies

| Domain | Train Pathologies (skill evolved on) | Test-Only Pathologies (zero-shot transfer) |
|---|---|---|
| Abdominal | appendicitis, cholecystitis, diverticulitis, pancreatitis | bowel obstruction, cholangitis, pyelonephritis |
| Chest/Cardiac | myocardial infarction, pulmonary embolism, CHF | aortic stenosis, mitral regurgitation |

### EvoTest Framework

Skills are evolved using an adapted [EvoTest](https://arxiv.org/abs/2503.02194)
framework with UCB tree exploration and regression protection:

1. **Episode 0** (baseline): Run agent on 10 train patients/pathology, no skill
2. **Episodes 1–9**: Claude Opus 4.6 analyzes failure trajectories + discharge
   summaries, generates improved skill. UCB selects best parent to evolve from;
   regression protection prevents carrying forward degraded skills.
3. **Test**: Best skill evaluated on held-out 100 patients/pathology across all
   pathologies (including 5 unseen ones).

### 3. Physical Examination Compliance

Hager et al. identified that LLMs skip physical examination (only 53% perform PE
first with WizardLM). Our mature evolved skills (mt=1024/2048/8192, episodes 2–9)
enforce PE-first at near-100%.

| Metric | Domain | Baseline | +Skill (mature) | Delta |
|---|---|---|---|---|
| PE performed first | Abdominal | 7.7% | 98.9% | +91.2pp |
| PE performed first | Chest | 5.3% | 99.2% | +93.9pp |
| PE performed at all | Abdominal | 77.3% | 99.8% | +22.5pp |
| PE performed at all | Chest | 48.9% | 99.9% | +51.0pp |

These averages cover mt=1024/2048/8192 (21 abdominal comparisons, 15 chest
comparisons). Mature skills enforce PE as the first clinical action.

**Note on mt=4096**: The skill tested at mt=4096 was episode 1 (abdominal) or
episode 4 (chest) — early skills that did not yet include the PE-first mandate.
At mt=4096, PE-first was 0.6% (abdominal) and 2.5% (chest) — actually lower
than baseline. However, PE-at-all still reached ~100%, meaning the skill ensured
PE was always performed, just not first. Mature skills (episode 2+) resolve this.

### 4. Laboratory Test Selection

Lab test appropriateness score (weighted by category, higher is better). Averaged
across all 4 max_tokens settings:

| Domain | Baseline | +Skill | Relative Improvement |
|---|---|---|---|
| Abdominal | 1.80 | 2.15 | +19.7% |
| Chest (MI/PE/CHF only) | 0.43 | 0.72 | +69.8% |

Note: Aortic stenosis and mitral regurgitation have lab score = 0 for both
baseline and skill (diagnosis is echocardiography-driven, not lab-driven).

### 5. Invalid Tool Hallucinations

Hager et al. reported tool hallucination every 2–5 patients. Averaged across all
4 max_tokens settings:

| Domain | Baseline | +Skill | Reduction |
|---|---|---|---|
| Abdominal | 17.2% | 9.6% | -44.4% |
| Chest | 32.1% | 31.4% | -2.4% |

Skills halve invalid tool calls on abdominal pathologies. Chest improvement is
negligible, likely because ECG/Echocardiogram tools add complexity beyond what
prompt-level skills can address.

### 6. Generalization to Unseen Pathologies

Skills were evolved on 4 abdominal + 3 cardiac pathologies, then tested zero-shot
on 5 additional pathologies never encountered during evolution. Averaged across all
4 max_tokens settings:

| Category | Avg Diagnosis Delta | N comparisons |
|---|---|---|
| Train pathologies | +9.3pp | 28 |
| Test-only (unseen) | +7.6pp | 20 |

By domain:

| Split | Avg Delta | N |
|---|---|---|
| Abdominal train | +8.2pp | 16 |
| Abdominal test-only (unseen) | **+10.3pp** | 12 |
| Chest train | +10.8pp | 12 |
| Chest test-only (unseen) | +3.6pp | 8 |

On abdominal conditions, unseen pathologies benefit *more* (+10.3pp) than trained
ones (+8.2pp), suggesting the skill captures transferable clinical reasoning
patterns rather than pathology-specific memorization. Chest test-only performance
is weaker (+3.6pp) because aortic stenosis and mitral regurgitation require
fundamentally different diagnostic workups (echocardiography-driven) compared to
the ischemia/thromboembolism-focused training conditions.

## Addressing Hager et al. Failure Modes

| # | Failure Mode | Paper Finding | Our Result |
|---|---|---|---|
| 1 | Poor diagnostic accuracy | 45–55% autonomous | +8–10pp avg improvement; 85% pancreatitis, 89% MI |
| 2 | Cannot interpret lab results | 26–77% correct | Lab scores +20% (abdominal), +70% (chest) |
| 3 | Skip physical examination | 53% PE first | PE-first: 8% to 99% with mature skills |
| 4 | Insufficient treatment | Miss surgery | Treatment parsing: 76% to 95% |
| 5 | Hallucinate tools | Every 2–5 patients | Invalid tools -44% (abdominal) |
| 6 | Sensitive to info quantity | Up to -18% | Not directly tested |
| 7 | Sensitive to info order | Up to 18% swing | Not directly tested |
| 8 | Sensitive to phrasing | "final" vs "main" | Structured skill reduces format errors |

## Limitations

1. **Mitral regurgitation**: The only pathology where the best skill decreased
   accuracy (-6.7pp). Smallest test set (N=15) and most
   echocardiography-dependent condition, poorly represented in the chest training
   set.

2. **Chest invalid tools**: Skills do not reduce tool hallucination on cardiac
   pathologies (32.1% to 31.4%), likely because ECG/Echocardiogram tools add
   complexity beyond what prompt-level skills can address.

3. **Single student model**: Primary results on Qwen3.5-35B-A3B only.
   Cross-model skill transfer (applying Qwen-evolved skills to other models)
   not tested.

4. **Single seed per evaluation**: Each test run used one seed. Statistical power
   comes from per-patient variation (N=100 per pathology), not repeated seeds.

5. **mt=4096 used early skill**: The default max_tokens=4096 tested an early
   episode skill (ep1 for abdominal, ep4 for chest) that predates PE-first
   enforcement. The mt=1024/2048/8192 settings tested mature skills. This makes
   PE-first results at mt=4096 non-comparable to the other settings.

6. **Cross-model comparison caveat**: Qwen+Skill matching Sonnet (8/12) uses
   best-per-pathology selection across different mt settings. At a fixed mt=4096,
   the comparison is 6/12 (essentially tied at 69.2% vs 70.5%).

## Next Steps

- [ ] **Chest tool hallucination**: Skills barely reduce invalid tool calls on
  cardiac pathologies (32.1% to 31.4%). Investigate ECG/Echocardiogram misuse
  patterns and add targeted tool-usage guidance to the Evolver prompt.
- [ ] **Treatment content accuracy**: Treatment *parsing* improved (76% to 95%)
  but Treatment *Match* (correct drug/procedure content) regressed during
  evolution. Evolver now has finding-driven drug guidance — validate this fixes
  the regression.
- [ ] **Structured evidence memory**: `evidence_memory=True` stores raw tool
  observations as a JSON dict (no reasoning, no differentials) for high
  signal-to-noise diagnosis. Run ablation: evidence_memory ON vs OFF.
- [ ] **Cross-model skill transfer**: Test evolved skills on additional student
  models via vLLM: MedGemma-27B (medical domain), Llama-3.3-70B-FP8 (general),
  gpt-oss-120B (reasoning MoE). Configs and vLLM flags ready.
- [ ] **Re-run mt=4096 with mature skill**: Current mt=4096 results used early
  skills (ep1/ep4) that lack PE-first enforcement. Re-test with ep8+ skill for
  fair comparison with other mt settings.
- [ ] **ToT agent**: Tree of Thoughts agent with breadth-first search over
  clinical reasoning paths. Evolution infrastructure supports `--agent ToT`.

## Reproducing Results

### Prerequisites

- vLLM server running Qwen3.5-35B-A3B (or compatible model)
- `ANTHROPIC_API_KEY` for Claude Opus 4.6 (evolver)
- MIMIC-CDM data in `data_splits/` (created by `scripts/split_data.py`)
- Python environment with Hager's framework dependencies

### Run evolutionary optimization + test

```bash
# Abdominal pathologies, 10 episodes, default mt=4096
bash scripts/evotest_full.sh 10 vLLM_Qwen3 claude-opus-4-6 True

# Chest pathologies
bash scripts/evotest_full.sh --condition chest 10 vLLM_Qwen3 claude-opus-4-6 True

# Max tokens ablation (e.g., mt=1024)
VLLM_MAX_TOKENS=1024 bash scripts/evotest_full.sh --experiment mt1024 10 vLLM_Qwen3
```

### Run test evaluation only (with existing skill)

```bash
# Abdominal — test best mt=8192 skill on 7 pathologies x 100 patients
bash scripts/evotest_test.sh skills/evo_patsim_mt8192/episode_8.md vLLM_Qwen3 True

# Chest — test best mt=1024 skill on 5 pathologies
bash scripts/evotest_test.sh --condition chest \
  skills/evo_patsim_chest_mt1024/episode_2.md vLLM_Qwen3 True
```

### Run cloud model baseline

```bash
bash scripts/cloud_baseline.sh claude-sonnet-4-6
```
